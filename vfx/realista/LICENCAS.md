# Licenças das texturas de VFX realistas (`public/vfx/realista/`)

Todas as texturas desta pasta foram reprocessadas (recortadas, reamostradas, recoloridas, montadas em atlas e comprimidas em WebP/KTX2) a partir das fontes abaixo. As fontes brutas ficam fora do projeto, em `/workspace/tripo_work/vfx/packs/` (inventário em `inventario.md`), e os scripts de montagem em `/workspace/tripo_work/vfx/build/`.

## Regras para Fab e SEAMPROOF

1. Usar só dentro do jogo (build do Vite em `dist/`, servido ao jogador). Isso é permitido pelas duas licenças.
2. Não publicar os PNG originais nem as pastas `packs/fab150` e `packs/seamproof` em repositório público, site, Discord, etc.
3. Não oferecer esta pasta `public/vfx/realista/` como "pacote de texturas" para download separado do jogo. Se o repositório do jogo for público, preferir manter estes arquivos fora do git (por exemplo, gerados pelo script de build ou baixados de um armazenamento privado na hora do deploy).
4. Os créditos de Unity Labs e Kenney são opcionais (CC0), mas é bom mantê-los em `CREDITOS.md`.
